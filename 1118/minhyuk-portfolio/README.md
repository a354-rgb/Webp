# 이민혁 포트폴리오 웹사이트

HTML, CSS, JavaScript로 제작한 반응형 개인 포트폴리오 템플릿입니다. 화이트·차콜·세이지 그린 색상 체계를 유지하며 데스크톱, 태블릿, 모바일 화면에 맞춰 레이아웃이 바뀝니다.

## 실행 방법

1. `minhyuk-portfolio` 폴더의 압축을 해제합니다.
2. `index.html` 파일을 브라우저에서 엽니다.
3. 개인 정보와 실제 프로젝트 자료를 입력한 뒤 새로고침합니다.

별도의 빌드 도구나 패키지 설치는 필요하지 않습니다. 웹 폰트는 Google Fonts를 통해 불러옵니다.

## 수정 방법

### 프로필 사진 교체

- `assets/profile.jpg` 파일을 본인 사진으로 덮어쓰세요.
- 파일명과 경로를 그대로 유지하면 HTML을 수정할 필요가 없습니다.
- 권장 비율은 세로형 4:5입니다. 이미지가 프레임에 맞춰 자동으로 잘립니다.

### 기본 정보 / 자기소개 수정

- `index.html`에서 이름, 전공, 한 줄 소개 및 ABOUT 영역의 플레이스홀더 문구를 수정하세요.
- `[학교명 / 재학 기간 / 학력 정보 입력]`, `[자기소개를 입력하세요]` 등 대괄호로 표시된 내용은 실제 정보로 교체하세요.
- 학력, 경력, 활동, 수상, 기술 숙련도 등 확인되지 않은 정보는 임의로 추가하지 않았습니다.

### 프로젝트 카드와 이미지 교체

- `index.html`의 `<!-- PROJECTS -->` 영역에서 카드 제목, 유형, 설명, 기술 태그를 수정하세요.
- 현재 프로젝트 이미지 3개는 실제 결과물을 표현하지 않는 교체용 SVG 미리보기입니다.
- 실제 프로젝트 캡처를 `assets/` 폴더에 저장한 다음, 해당 카드의 `<img src="assets/project-placeholder-01.svg">` 경로를 새 이미지 경로로 바꾸세요.
- 프로젝트 저장소 주소가 준비되면 카드 하단의 `project-link-placeholder` 문구를 실제 `<a href="프로젝트 URL">저장소 보기 ↗</a>` 링크로 교체하세요. 세 카드에 임의로 동일한 저장소 주소를 연결하지 않았습니다.
- 카드 수를 늘리거나 줄여도 그리드가 자동으로 재배치됩니다.

### GitHub 주소 변경

`index.html`에서 `https://github.com/a354-rgb/Webp`를 검색해 원하는 주소로 변경하세요. 현재 주소는 상단 메뉴, 프로젝트 섹션, CONTACT, Footer에 연결되어 있습니다.

### 디자인 변경

`style.css` 상단 `:root`에 정의된 색상, 최대 콘텐츠 너비, 헤더 높이 변수를 수정하면 전체 디자인에 일관되게 적용됩니다. 미디어 쿼리는 태블릿(1020px 이하), 모바일(760px 이하), 작은 모바일(390px 이하) 순서로 정의되어 있습니다.

## 반응형 및 사용성

- 데스크톱: 프로젝트 카드 3열
- 태블릿: 프로젝트 카드 2열
- 모바일: 프로젝트 카드 1열, 접이식 네비게이션
- 키보드 포커스 표시 및 메뉴의 Escape 닫기 지원
- 사용자가 시스템에서 동작 줄이기를 설정한 경우 애니메이션 최소화
- 작은 글씨와 회색 텍스트의 대비를 개선한 색상 사용
