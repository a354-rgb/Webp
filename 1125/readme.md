# 도서관 좌석 예약

[**도서관 좌석 예약 웹 사이트 바로가기**](https://url.kr/kzu39u)

Google Apps Script(GAS)와 Google 스프레드시트를 활용하여 제작한 도서관 좌석 예약 웹 애플리케이션입니다.

본 프로젝트는 **ChatGPT를 활용한 바이브 코딩(Vibe Coding)** 방식으로 개발했습니다. 자연어로 기능과 요구사항을 설명하고, ChatGPT의 도움을 받아 코드 작성, 수정 및 오류 해결을 진행했습니다.

## 1. 프로젝트 개요

- **프로젝트명:** 도서관 좌석 예약
- **개발 방식:** ChatGPT를 활용한 바이브 코딩
- **목적:** 도서관 좌석 예약 및 예약 현황 관리
- **프론트엔드:** HTML, CSS, JavaScript
- **백엔드:** Google Apps Script
- **데이터베이스:** Google 스프레드시트
- **배포 환경:** Google Apps Script 웹 앱

## 2. 주요 기능

### 2.1 좌석 예약

- 사용자명 입력
- 원하는 좌석 선택
- 인증 번호 설정
- 예약 완료 메시지 출력
- 예약된 좌석을 좌석 배치도에 표시

사용자명, 좌석, 인증 번호가 모두 입력되어야 예약할 수 있습니다.

### 2.2 좌석 현황 확인

- 전체 좌석 수: 50석
- 잔여 좌석 수 표시
- 예약 완료 좌석 표시
- 예약 가능한 좌석과 선택한 좌석 구분

좌석은 5개 열(A~E열), 각 열 10석으로 구성됩니다.

| 열 | 좌석 번호 |
|---|---|
| A열 | 1~10번 |
| B열 | 11~20번 |
| C열 | 21~30번 |
| D열 | 31~40번 |
| E열 | 41~50번 |

### 2.3 예약 정보 조회

예약 시 설정한 인증 번호를 입력하여 예약 정보를 확인할 수 있습니다.

조회 결과:
- 예약자명
- 예약 좌석 번호
- 좌석 위치

### 2.4 예약 취소

- 인증 번호를 통한 예약 확인
- 예약 취소 확인 메시지 출력
- 예약된 좌석 해제
- 잔여 좌석 수 자동 복구
- 취소된 좌석을 다시 예약 가능 상태로 변경

### 2.5 예약 오류 처리

다음과 같은 상황에서 오류 메시지를 출력합니다.

- 사용자명을 입력하지 않은 경우
- 좌석을 선택하지 않은 경우
- 인증 번호를 입력하지 않은 경우
- 이미 예약된 좌석을 선택한 경우
- 인증 번호가 올바르지 않은 경우
- 예약 가능한 좌석이 없는 경우

## 3. Google Apps Script(GAS) 사용

### GAS란?

Google Apps Script(GAS)는 Google에서 제공하는 클라우드 기반 스크립트 개발 환경입니다. JavaScript를 기반으로 Google 스프레드시트와 같은 Google 서비스에 접근하고, 웹 애플리케이션을 제작하거나 자동화 기능을 구현할 수 있습니다.

별도의 웹 서버를 구축하지 않고도 서버 측 코드를 실행하고 웹 앱으로 배포할 수 있다는 장점이 있습니다.

### 본 프로젝트에서의 GAS 활용

본 프로젝트에서는 GAS를 백엔드로 사용하여 다음 기능을 처리합니다.

- 웹 페이지 실행 및 제공
- 좌석 예약 요청 처리
- 예약 정보 조회
- 예약 취소 처리
- 스프레드시트 데이터 읽기 및 저장
- 잔여 좌석 수 갱신
- 중복 예약 및 입력값 검증

### GAS 사용 방법

1. [Google Apps Script](https://script.google.com/)에 접속합니다.
2. 새 프로젝트를 생성합니다.
3. `Code.gs`에 서버 측 JavaScript 코드를 작성합니다.
4. HTML 파일을 추가하여 웹 페이지를 구성합니다.
5. Google 스프레드시트와 연결하여 예약 데이터를 저장합니다.
6. **배포 → 새 배포 → 웹 앱**을 선택합니다.
7. 실행 권한과 접근 권한을 설정한 후 배포합니다.
8. 생성된 웹 앱 URL을 통해 사이트에 접속합니다.

배포 설정에 따라 웹 앱의 실행 권한 및 접근 가능한 사용자가 달라질 수 있습니다.

## 4. URL 단축 과정

Google Apps Script 웹 앱을 배포하면 긴 형태의 웹 앱 URL이 생성됩니다. 이를 공유하기 편리하도록 `url.kr`을 이용해 단축 URL로 변환했습니다.

### URL 단축 방법

1. Google Apps Script에서 웹 앱을 배포합니다.
2. 배포 완료 화면에서 웹 앱 URL을 복사합니다.
3. [url.kr](https://url.kr/)에 접속합니다.
4. URL 입력란에 복사한 GAS 웹 앱 URL을 붙여 넣습니다.
5. URL 단축 기능을 실행합니다.
6. 생성된 단축 URL을 복사합니다.
7. README 및 사용자에게 공유할 링크에 단축 URL을 사용합니다.

### 단축 URL 사용 목적

- 긴 웹 앱 주소를 간결하게 표시
- 링크 공유 및 전달 편의성 향상
- README에서 웹 사이트 링크를 보기 쉽게 구성

**주의:** GAS 웹 앱을 새 버전으로 배포하거나 배포 URL이 변경된 경우, 단축 URL이 올바른 주소를 가리키는지 확인해야 합니다.

## 5. 데이터베이스 구조

Google 스프레드시트를 데이터베이스로 사용합니다.

### DB 시트 정보

- **스프레드시트 시트명:** 예약정보
- **총 좌석 수:** 50석

### DB 헤더

| 사용자명 | 좌석 번호 | 잔여 좌석수 | 인증 번호 |
|---|---:|---:|---|
| 홍길동 | 5 | 49 | 1234 |
| 김철수 | 12 | 49 | 5678 |

각 예약 정보는 스프레드시트에 저장되며, 예약 및 취소 시 잔여 좌석 수가 갱신됩니다.

인증 번호는 예약 조회 및 취소에 사용되므로 다른 사람에게 공유하지 않아야 합니다.

## 6. 사용 방법

### 좌석 예약

1. 웹 사이트에 접속합니다.
2. 좌석 배치도에서 원하는 좌석을 선택합니다.
3. 사용자명을 입력합니다.
4. 인증 번호를 4~12자리 숫자로 설정합니다.
5. 좌석 예약하기 버튼을 클릭합니다.
6. 예약 완료 메시지와 좌석 정보를 확인합니다.

### 예약 조회

1. 예약 조회 및 취소 영역으로 이동합니다.
2. 예약 시 사용한 인증 번호를 입력합니다.
3. 예약 조회하기 버튼을 클릭합니다.
4. 예약자명과 좌석 위치를 확인합니다.

### 예약 취소

1. 예약 조회 및 취소 영역에서 인증 번호를 입력합니다.
2. 예약 취소하기 버튼을 클릭합니다.
3. 취소 확인 창에서 확인을 선택합니다.
4. 예약 취소 완료 메시지를 확인합니다.

취소된 좌석은 다시 예약할 수 있으며 잔여 좌석 수가 갱신됩니다.
