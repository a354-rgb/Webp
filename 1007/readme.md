#### 2. 자바스크립트 언어 개요 및 특징
자바스크립트(JavaScript)는 웹 페이지의 동적 행위를 제어하기 위해 웹 브라우저에서 실행되는 인터프리터 방식의 스크립트 언어입니다.
##### 자바스크립트 언어의 주요 특징
*   **인터프리터 언어:**  별도의 컴파일 과정 없이 브라우저의 자바스크립트 엔진에 의해 한 줄씩 즉시 해석되고 실행됩니다.
*   **객체 기반 언어:**  클래스 정의 없이도 객체를 직접 다루거나 생성할 수 있는 객체 기반 언어입니다.
*   **동적 타입 언어:**  변수의 데이터 타입을 명시하지 않으며, 대입되는 값에 따라 변수의 타입이 동적으로 결정됩니다.
*   **C 언어 계열 구문:**  조건문(if-else, switch), 반복문(for, while), 연산자 등의 기본 제어 구문이 C 언어와 매우 유사합니다.
##### 자바스크립트 코드 작성 위치 4가지
1.  **`<script>` 태그 내 작성:**  `<head>`나 `<body>` 태그 내에 `<script> ... </script>` 블록을 작성합니다.
2.  **HTML 태그의 이벤트 리스너 속성에 작성:**  `onclick`, `onmouseover` 등의 이벤트 속성에 직접 실행 코드를 지정합니다.
3.  **외부 자바스크립트 파일 연결:**  별도의 `.js` 파일로 코드를 작성한 후 `<script src="file.js"></script>`로 연결합니다.
4.  **URL 위치에 작성:**  `href="javascript:코드"` 형태로 하이퍼링크 클릭 시 스크립트를 실행합니다.

#### 3. 자바스크립트 구성 요소별 구분 및 기능 표
자바스크립트의 핵심 요소는 변수, 입출력 다이얼로그, 제어문, 함수로 구분됩니다.
| 구분 | 역할 및 특징 | 주요 키워드 및 함수 예시 |
| ------ | ------ | ------ |
| **변수 및 상수 선언** | 데이터 저장 및 블록/함수 스코프 지정 | `let` (블록 스코프 변수), `const` (상수), `var` (함수 스코프 변수) |
| **다이얼로그 입출력** | 사용자 상호작용을 위한 브라우저 대화상자 | `prompt()` (입력), `confirm()` (확인/취소 선택), `alert()` (경고 메시지 출력) |
| **데이터 연산 및 제어** | 데이터 연산 및 조건별 흐름 제어 | `+`, `-`, `===`, `&&`, `||`, `if-else`, `switch`, `for`, `while`, `break` |
| **전역 및 사용자 함수** | 코드 재사용 및 유틸리티 기능 실행 | `eval()`, `parseInt()`, `parseFloat()`, `isNaN()`, `isFinite()`, `function` 키워드 |

#### 4. HTML5 / JavaScript 구문 및 실습 코드 사용법
##### 기본 입출력 다이얼로그 및 조건문/반복문 활용 예시
`<head>` 태그 내 `<script>` 블록에 사용자 입력을 받아 조건식으로 판단하고 결과를 출력하는 완전한 HTML5 기본 예제입니다.
```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>자바스크립트 다이얼로그 및 제어문</title>
  <script>
    // 사용자로부터 점수 입력받기
    let inputStr = prompt("점수를 입력하세요", "90");
    let score = parseInt(inputStr);

    // confirm 다이얼로그로 처리 여부 확인
    if (confirm("입력한 점수 " + score + "점을 처리하시겠습니까?")) {
      let grade;
      if (score >= 90) {
        grade = "A";
      } else if (score >= 80) {
        grade = "B";
      } else {
        grade = "C";
      }
      alert("성적 산출 완료: " + grade + "학점");
    } else {
      alert("취소되었습니다.");
    }
  </script>
</head>
<body>
  <h3>자바스크립트 다이얼로그 실행 결과</h3>
  <hr>
  <p>브라우저 대화상자를 통한 데이터 입출력 실습입니다.</p>
</body>
</html>
```

##### 전역 함수 및 사용자 정의 함수 작성법 예시
`eval()`, `isNaN()`, `parseInt()` 등의 전역 함수 활용과 `function` 키워드를 사용한 사용자 정의 함수 호출의 완전한 HTML5 예제입니다.
```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>전역 함수 및 사용자 정의 함수</title>
  <script>
    // 두 수의 합을 구하는 사용자 정의 함수
    function adder(a, b) {
      let sum = a + b;
      return sum;
    }

    // 전역 함수 검증 및 수식 계산 함수
    function calculate() {
      let res = eval("2 * 3 + 4"); // 수식 문자열 즉시 계산 (결과: 10)
      let val = parseInt("32px");  // 정수 32 추출
      
      if (isNaN(val)) {
        alert("숫자가 아닙니다.");
      } else {
        let total = adder(res, val); // adder 함수 호출 (10 + 32)
        document.write("최종 계산 결과: " + total);
      }
    }
  </script>
</head>
<body onload="calculate()">
  <h3>전역 함수 및 사용자 정의 함수 실습</h3>
  <hr>
  <p>페이지 로드 시 자바스크립트 계산 함수가 실행됩니다.</p>
</body>
</html>
```

#### 5. 자바스크립트 핵심 문법 및 활용 절차 정리
##### 변수 선언 규칙 및 다이얼로그 활용 규격
1.  **변수 선언 키워드:**  `let`은 재선언이 불가능한 블록 스코프 변수이고, `const`는 선언 시 반드시 초기화해야 하는 상수이며, `var`는 함수 스코프 변수입니다.
2.  **다이얼로그 반환값:**  `prompt()`는 입력된 문자열을 반환(취소 시 `null`), `confirm()`은 [확인] 클릭 시 `true`, [취소] 클릭 시 `false`를 반환합니다.
##### 함수 작성 및 전역 함수 디버깅 절차
1.  **전역 함수 활용:**  `isNaN(val)`은 수치 여부를 안전하게 검사할 때 사용하며, `parseInt(str)`는 문자열 앞부분의 정수를 추출합니다.
2.  **함수 정의 및 호출:**  `function 함수명(매개변수)` 구조로 정의하며, `return` 문으로 처리 결과를 반환합니다.
